# Java-basico

Exercícios de Java básico que eu já tinha feito em provas do curso — resolvi juntar aqui pra treinar arrays, laços e condicionais antes de entrar em POO de verdade.

## O que tem aqui

- **Time de futebol** — guarda o técnico e os 11 jogadores num array de String e imprime a lista numerada
- **Notas da turma** — lê 6 notas do usuário (validando pra não aceitar número negativo), ordena com `Arrays.sort`, e mostra a menor, a maior e a média da turma
- **Par/ímpar e múltiplos de 3 e 5** — laço de 1 até 50 que diz se o número é par ou ímpar, e se é múltiplo de 3, de 5 ou dos dois

## O que eu treinei com isso

Array (declarar, preencher, percorrer com `for`), `Scanner` pra ler entrada do usuário, validação com `while`, `Arrays.sort()`, e um `do-while` com um monte de `if`/`else if` encadeado.

## Como rodar

```
javac Main.java
java Main
```

(cada exercício tá no seu próprio arquivo/pasta)
